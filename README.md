# Crypto Trading System

A professional Python project for real-time cryptocurrency trading analysis and position management using Binance WebSocket and REST API.

## Features

- Real-time trade analysis via Binance WebSocket for multiple trading pairs.
- Historical kline data retrieval via Binance REST API.
- Technical indicators (RSI, ATR, EMA) and price zone analysis.
- Position management with optional Stop Loss/Take Profit (SL/TP).
- Support for multiple trading pairs (e.g., BTCUSDT, ETHUSDT).
- Data storage in JSON files.
- Modular and maintainable codebase with logging and unit tests.
